วิธีคิด — เราเลือกชื่อให้คุณอย่างไร?

ระบบ Miracle Names คัดและจัดอันดับชื่อมงคลด้วย 3 มิติ
ผสมผสาน Data Science กับตำราโหราศาสตร์ไทย

1
คัดชื่อให้เหมาะกับวันเกิด
🗓️
  • ตัดชื่อที่มีอักษรกาลกิณีตามวันเกิดออกก่อน เพื่อให้ชื่อที่เหลือปลอดภัยตามหลักโหราศาสตร์
  • หากเลือกโหมด ชื่อ + นามสกุล ระบบจะตรวจอักษรกาลกิณีเฉพาะชื่อ และนำนามสกุลมาคำนวณเลขศาสตร์ร่วมกัน
2
เรียงชื่อจาก 3 มิติ
⚖️
⭐ เลขศาสตร์ 🎯 ความหมาย 🎶 เสียงชื่อ
  • เลขศาสตร์ — คัดคู่เลขที่ดีและให้คะแนนตามตำรา
  • ความหมาย — เลือกชื่อที่มีความหมายใกล้เคียงกับสิ่งที่คุณต้องการ
  • เสียงชื่อ — ดูความไพเราะ ความง่ายในการออกเสียง และจังหวะของชื่อ
  • คุณปรับ น้ำหนักทั้ง 3 มิติ ได้เอง ชื่อที่ตรงกับความต้องการมากกว่าจะขึ้นก่อน
  • หากคะแนนเท่ากัน ระบบจะใช้ความไพเราะของชื่อช่วยตัดสิน
3
มีชื่อให้เลือกหลากหลาย
✨
  • ไม่ตัดชื่อเพราะจำนวนพยางค์ จึงมีทั้งชื่อสั้นและชื่อยาวให้เลือก
  • เมื่อใช้นามสกุล ระบบจะคำนวณชื่อเต็มใหม่ทุกครั้ง เพื่อหาชื่อที่เข้ากับนามสกุลของคุณมากที่สุด
✨

อัลกอริทึมการจัด Ranking นี้มีคุณภาพสูงมาก ทั้งในมิติของความถูกต้องตามตำราโหราศาสตร์
และความแม่นยำในการวิเคราะห์เสียงและความหมายของชื่อ
