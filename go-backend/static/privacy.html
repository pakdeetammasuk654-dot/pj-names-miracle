นโยบายความเป็นส่วนตัว แอปพลิเคชัน "ชื่อดี"

ปรับปรุงล่าสุดเมื่อ: 15 กันยายน 2026

1. บทนำและการคุ้มครองข้อมูล

แอปพลิเคชัน "ชื่อดี" (Miracle Names) และเว็บไซต์ ชื่อดี.com ให้ความสำคัญสูงสุดกับการคุ้มครองข้อมูลความเป็นส่วนตัวของผู้ใช้งาน เอกสารฉบับนี้อธิบายถึงนโยบายและแนวปฏิบัติในการจัดการข้อมูลของผู้ใช้เมื่อใช้งานแอปพลิเคชันและบริการของเรา

2. ข้อมูลที่เราจัดเก็บ

เราเก็บข้อมูลเท่าที่จำเป็นต่อฟีเจอร์ที่คุณเลือกใช้ โดยข้อมูลที่เกี่ยวกับการแชตจะถูกเก็บบนเซิร์ฟเวอร์จนกว่าคุณจะสั่งลบบทสนทนา:

  • ข้อมูลค้นหาตั้งชื่อและวันมงคล: ข้อมูลที่คุณกรอก เช่น วันเกิด นามสกุล และเงื่อนไขที่เลือก จะถูกส่งไปยัง API เพื่อคำนวณและส่งผลลัพธ์กลับ แอปไม่จำเป็นต้องใช้บัญชีผู้ใช้สำหรับการค้นหา
  • ข้อมูลแชตช่วยเหลือ: หากคุณเริ่มแชต เราจัดเก็บรหัสบทสนทนาและรหัสเข้าถึงแบบสุ่ม ชื่อเรียกและรูปประจำตัวที่เลือก (ถ้ามี) ข้อความ รูปที่แนบ และเวลาของข้อความ เพื่อให้บริการและตอบกลับ รูปแนบจัดเก็บบนเซิร์ฟเวอร์
  • การแจ้งเตือนแชต: หากเปิดการแจ้งเตือน แอปจะส่ง device token ของ APNs (Apple) หรือ Firebase Cloud Messaging (Google) ให้เซิร์ฟเวอร์เพื่อส่งการแจ้งเตือนเมื่อมีคำตอบ โดยผู้ให้บริการแจ้งเตือนจะประมวลผล token และเนื้อหาการแจ้งเตือน
  • การซื้อในแอป: Apple หรือ Google ประมวลผลการชำระเงินตามเงื่อนไขของแพลตฟอร์ม แอปส่งรหัสธุรกรรมไปตรวจสอบสิทธิ์กับเซิร์ฟเวอร์ และจัดเก็บ token สิทธิ์ใช้งานไว้บนอุปกรณ์
  • เว็บไซต์: เว็บไซต์อาจใช้ Google Analytics 4 เพื่อวัดการเข้าชม ข้อมูลนี้เกี่ยวกับการใช้งานเว็บไซต์ ไม่ใช่การติดตามโฆษณาภายในแอป

3. การใช้งานข้อมูล

เราใช้ข้อมูลเพื่อให้บริการที่คุณร้องขอ ดูแลบทสนทนาและส่งการแจ้งเตือนแชต ตรวจสอบสิทธิ์ซื้อในแอป และปรับปรุงเว็บไซต์ตามสถิติการเข้าชม

  • คำนวณและจัดอันดับชื่อมงคลตามเงื่อนไขเลขศาสตร์ พลังเงา และความหมายที่คุณเลือก
  • สร้างการ์ดมงคลสำหรับบันทึกลงในอุปกรณ์ของคุณ
  • ยืนยันและคืนสิทธิ์การใช้งานซื้อสินค้าในแอป (In-App Purchase Restoration)

4. ความปลอดภัยของข้อมูล

การเชื่อมต่อระหว่างแอปกับเซิร์ฟเวอร์ใช้ HTTPS ข้อมูลแชตและรูปแนบจะเข้าถึงได้โดยทีมบริการเพื่อให้ตอบคำถาม เราไม่ขายข้อมูลส่วนบุคคล

5. สิทธิ์ของผู้ใช้และการลบข้อมูล (Data Deletion)

ไม่ต้องมีบัญชีผู้ใช้ ในแอปเวอร์ชันที่มีเมนู ลบแชตและข้อมูลทั้งหมด คุณสั่งลบบทสนทนา ข้อความ รูปแนบ และ token แจ้งเตือนที่ผูกกับบทสนทนานั้นได้จากหน้าสนทนา หากใช้แอปเวอร์ชันที่ยังไม่มีเมนูนี้ หรือลบผ่านแอปไม่ได้ โปรดส่งคำขอพร้อมรหัสบทสนทนามาที่ support@ชื่อดี.com การถอนการติดตั้งแอปเพียงอย่างเดียวไม่ลบข้อมูลแชตบนเซิร์ฟเวอร์

6. การเปลี่ยนแปลงนโยบาย

เราอาจปรับปรุงนโยบายความเป็นส่วนตัวนี้เป็นครั้งคราวตามความเหมาะสม โดยจะแสดงวันที่อัปเดตล่าสุดที่ด้านบนของหน้านี้
